# Node.js + MySQL Project

A simple CRUD application built with **Node.js** and **MySQL**. This project demonstrates basic database operations such as creating a database and table, inserting, reading, updating, deleting records, and altering tables.

## Features
- MySQL Database Connection
- Create Database & Table
- Insert Records
- Read Records
- Update Records
- Delete Records
- Alter Table (Add/Drop Column)
- Drop Table
